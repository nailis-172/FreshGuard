# FreshGuard

## Sistem Monitoring Penyimpanan Sayur dan Buah

FreshGuard merupakan proyek yang dibuat untuk memantau kondisi penyimpanan sayur dan buah. Sistem ini menampilkan informasi suhu, kelembapan, dan status kondisi penyimpanan melalui dashboard. Data monitoring juga disimpan menggunakan Firebase Realtime Database.

## Fitur

- Monitoring suhu.
- Monitoring kelembapan.
- Status kondisi penyimpanan.
- Notifikasi kondisi penyimpanan.
- Riwayat monitoring.
- Penyimpanan data menggunakan Firebase Realtime Database.

## Teknologi

- HTML
- CSS
- JavaScript
- Python
- Firebase Realtime Database

## Cara Menjalankan

1. Buka folder FreshGuard menggunakan Visual Studio Code.
2. Jalankan "index.html" menggunakan Live Server.
3. Dashboard akan terbuka di browser.

Program Python dapat dijalankan melalui terminal dengan perintah:

python FreshGuard.py

## Keterangan

Dashboard menggunakan data simulasi yang dikirim ke Firebase Realtime Database. Program Python merupakan program terpisah untuk menentukan status berdasarkan suhu dan kelembapan.

## Tujuan

Membantu memantau kondisi penyimpanan sayur dan buah agar kualitas bahan pangan dapat lebih terjaga.
